    What this demo stands in for

    The real application runs inside Salesforce. This page simulates the same rules in your browser so the workflow can be shown without a Salesforce login.

    Worker profiles
    Four profiles, roles and permission sets: Support Agent, Team Lead, Support Manager, Case Admin.
    Escalate button
    The escalateCase Lightning Web Component quick action, backed by EscalationService.
    Clock buttons
    CaseEscalationBatch, scheduled every 15 minutes, which escalates cases past their SLA.
    Matrix
    The Escalation_Policy__mdt custom metadata type, editable without code.
    History
    Escalation_Log__c records written by CaseTrigger, shown in the Escalation History component.
    Who gets the case
    The least-loaded active user in the next role, or that level's queue if nobody holds the role.

    Data lives only in this browser.
