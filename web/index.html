    How this works in Salesforce

    The real application runs inside Salesforce. This page copies the same rules so it can be tried without a Salesforce login.

    Roles
    Profiles, roles and permission sets for Support Agent, Team Lead, Support Manager and Case Admin.
    Escalate button
    A Lightning Web Component (escalateCase) that calls Apex (EscalationService).
    Automatic escalation
    An Apex job (CaseEscalationBatch) that runs every 15 minutes.
    Deadlines
    Custom metadata (Escalation_Policy__mdt) that admins edit without code.
    History
    An Escalation_Log__c record for every move, written by a trigger.
    Who gets the case
    The person in the next role with the fewest open cases.
